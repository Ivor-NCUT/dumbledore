# Raw Materials

这里保存用户发送给 Agent 的知识性材料 Markdown 原文。

使用原则：

- 每份材料在用户确认写入后，优先落到 `raw/`，再进入结构化沉淀流程。
- 文件尽量保留原始结构、段落和标题。
- 文件名建议使用 `YYYYMMDD_slug.md`。
- 如果原始内容来自网页、录音转写或聊天记录，可以在文件开头补充来源链接、抓取时间和必要上下文。
- 如果材料包含高敏信息，先按 `ACCESS_POLICY.md` 做脱敏，再决定是否保留全文。

`raw/` 不是结构化知识页，它保存的是输入材料本身。结构化沉淀仍应进入 `brain/sources/`、`atoms/atoms.jsonl`、`brain/concepts/`、`brain/methods/`、`brain/problems/` 和 `brain/skill-ideas/`。
